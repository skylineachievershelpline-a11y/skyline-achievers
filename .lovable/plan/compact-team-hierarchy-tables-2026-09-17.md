# Compact team hierarchy tables

## Goal
Replace the oversized team cards in the member and admin areas with the selected compact, reference-style hierarchy table while preserving all current member-management actions.

## Member team page
- Add a compact toolbar with member search, status filtering, selection, and an Add member action.
- Show the signed-in upline as the root row and direct trainees as indented rows with subtle hierarchy connectors.
- Keep each trainee's ID, phone, training progress, joined date, status, block/unblock, and permanent remove controls.
- Add bulk block, unblock, and remove actions for selected trainees.

## Admin members panel
- Replace large member cards with dense rows using the same visual language.
- Keep search and status filters, and retain rank, account status, access, password reset, and permanent delete controls.
- Add row selection and bulk status/access/delete actions using the existing member operations.

## Visual direction
- Use the selected Midnight + Silver palette with electric-blue and cyan emphasis.
- Use compact table spacing, slim hierarchy rails, a highlighted selection state, and restrained depth.
- Use a dense two-line mobile row layout with no horizontal overflow.

## Validation
- Confirm searches, filters, individual actions, and bulk actions work.
- Check desktop and phone layouts for readable rows and zero overflow.
