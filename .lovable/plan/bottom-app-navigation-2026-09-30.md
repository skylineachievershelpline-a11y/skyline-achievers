# Bottom app navigation

## Goal
Replace the member and Beginners Training side menus with the phone-style bottom navigation shown in the supplied video.

## Changes
- Move every current menu section into a fixed bottom navigation strip.
- Keep the active section visually raised and highlighted like the video.
- Make the full list horizontally swipeable so no section is removed or clipped.
- Include Settings in the bottom navigation and preserve locked-section messages, account switching, logout, and all existing destinations.
- Add safe bottom spacing so page content stays visible above the navigation on phones.

## Validation
- Check member and Beginners Training screens at phone and desktop sizes.
- Verify navigation, locked items, Settings, and horizontal swiping remain usable.
