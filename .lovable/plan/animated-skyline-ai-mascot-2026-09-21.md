# Animated Skyline AI mascot

## What will change
- Use the supplied Skyline robot as the visible identity for Skyline Achievers AI.
- Add a floating, clickable robot on the member dashboard while keeping the existing AI button.
- Animate the robot as a layered character: flying paths, turns, tilts, and independently moving arms and legs.
- Show the same character inside chat with distinct thinking and answer-ready reactions.

## Interaction and accessibility
- Clicking the flying robot opens Skyline Achievers AI.
- Keep the robot clear of dashboard controls on phone and desktop.
- Reduce or stop continuous movement when the device requests reduced motion.

## Technical details
- Store the supplied transparent artwork as an app asset.
- Build reusable mascot states from layered crops of the same artwork, without changing the Skyline brand.
- Verify the dashboard and chat at phone and desktop sizes, then check the app for errors.
