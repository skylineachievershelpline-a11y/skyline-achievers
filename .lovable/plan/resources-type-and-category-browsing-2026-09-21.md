# Resources Type and Category Browsing

## What will change
- Keep the resource-type choices visible at the top: All, Video, Picture, PDF, Audio, Presentation, Book, Link, and Note.
- After selecting a type, show only categories containing that type of item.
- Opening a category will show every matching item inside it, including multiple pictures, videos, PDFs, or links.
- Keep uncategorized matching items available under “Other material”.
- Make picture resources visibly previewable when opened while preserving existing download/share behavior.

## Technical details
- Rework the Resources page filtering order to: type selection → filtered category tiles → category items.
- Remove the current category-only early screen that hides the type choices.
- Keep the existing admin upload and category assignment system unchanged.
- Verify the mobile layout shown in the screenshot and the relevant build output.
